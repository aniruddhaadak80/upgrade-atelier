# Security policy

## Reporting

Please report suspected vulnerabilities privately through the repository’s GitHub security advisory form. Do not open a public issue with exploit details or a live secret.

Include the affected route, reproduction steps, impact, and whether user-created records or credentials are involved.

## Data handling

Upgrade Atelier stores package names, versions, review notes, and audit payloads. Do not submit secrets, private repository URLs, access tokens, or personal data in package names or notes.

The SHA-384 chain is tamper-evident for internal record consistency. It is not a digital signature and does not establish upstream package provenance.

## Supported versions

Security fixes are applied to the default branch and the latest deployed version. Please include the commit or deployment alias when reporting an issue.
